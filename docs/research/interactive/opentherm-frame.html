OpenTherm frame lab

Every OpenTherm conversation is one 32-bit frame from the thermostat (master) and one 32-bit frame back from the boiler (slave). Build a frame, see its bits, parity and Manchester waveform, or paste a hex frame from a log to decode it.

Examples:

Waveform: start bit + 32 bits + stop bit = 34 bit times = 34 ms. Each bit has a transition in the middle: a '1' goes active→idle, a '0' idle→active (Manchester / bi-phase-L). For the master, "active" is the high line voltage (15–18 V); for the boiler, it is the high loop current (17–23 mA).
